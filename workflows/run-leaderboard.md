# 单榜单执行工作流

从工程根目录执行。输入为用户提供的榜单 URL、授权范围和资源/网络限制。
读取 `skills/darvin-auto-benchmark/SKILL.md`，由它按需加载平台、飞书、
开源基线及镜像技能；不要把它们的业务逻辑复制到外层。

先读用户提供的已有检查点和对应运行记录，确认是否已有
提交或运行中的工作。已有任务只恢复跟踪；若用户明确要求新的端到端验证，
先对账再创建独立运行记录，不能拿旧回执当新流程成功。

阶段：要求确认 → 基线真实推理 → 容器 HTTP 验证 → 发布 READY → 提交回执
→ 任务/评测完成 → 得分及排名确认。各阶段由技能驱动执行，不能只输出计划。
每阶段保留来源、命令、关键产物与结果；失败保留准确证据和下一步。

完成时交付所用代码、镜像身份、提交/任务 ID、评测结果及未确认项。
不承诺任意榜单必然成功：登录、权限、缺失合同和资源限制可能需要用户介入。
当前只验证图像鉴伪；不要擅自扩展其他榜单或优化模型分数。
